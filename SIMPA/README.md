Projeto Integrador focado no combate à evasão no ensino superior através de métricas, indicadores e Inteligência Artificial.

## 🚀 Como executar

1. Instale as dependências:
   `ash
   pip install -r app/requirements.txt
   `
2. Inicie o servidor:
   `ash
   cd app
   python main.py
   `
3. Abra o navegador em: [http://127.0.0.1:8000](http://127.0.0.1:8000)
