Projeto Integrador focado no combate à evasão no ensino superior através de métricas, indicadores e Inteligência Artificial.

## 🚀 Como executar

### Backend Django (API REST + Produção)
```bash
cd SIMPA/django_backend
python manage.py migrate
python manage.py runserver
```
Acesse a API em: [http://127.0.0.1:8000/api/](http://127.0.0.1:8000/api/)

### Execução dos Testes Automatizados
```bash
cd SIMPA/django_backend
python manage.py test
```

### Documentação e Diagramas UML
* Modelagem de Casos de Uso e Classes: [`SIMPA/docs/Modelagem_UML.md`](./docs/Modelagem_UML.md)

### Protótipo Rápido (Flask)
```bash
cd SIMPA/app
python main.py
```
